# Sketch 001: Today Page — Focus & Rhythm

## Design Question

The current Today page shows three equal-weight cards (stats / progress /
actions). None of them answers "what should I do right now." Which framing
of the home screen works best?

## How to View

Open `.planning/sketches/001-today-focus/index.html` in a browser.

## Variants

- **A: 焦点任务** — conservative refinement: one adaptive "do this now" hero, a checkable day-plan list, stats demoted to a single footer line.
- **B: 今日节奏** — the day as an ordered timeline (review → new → consolidate → quiz) with per-step start buttons; 12-week heatmap replaces the 7-day bars.
- **C: 词典头版** — boldest: the home page as a dictionary front page — daily-word entry as the hero, tasks as a dotted-leader table of contents.

## What to Look For

- Does the hero number (A) or the timeline (B) better answer "what now"?
- Does C's editorial framing feel delightful or gimmicky on the 30th open?
- Heatmap (B) vs 7-day bars: which makes the streak feel more valuable?
- All variants keep the ink-and-paper language; C stretches it the furthest.
