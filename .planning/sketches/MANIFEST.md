# Sketch Manifest

## Design Direction

Improve the existing app's UX while staying inside (or deliberately
stretching) the established "Ink and Paper" language — dictionary
typesetting, warm paper, near-black ink, vermilion strictly as annotation.
The three sketches attack the three highest-traffic surfaces: the home
screen's sense of "what now", the quiz hub's seven-mode navigation, and
the review card's grading feel. All mockups run at the app's 375px design
width, reuse the real tokens (mirrored in `themes/default.css`), and use
real entries from the word library as content.

## Reference Points

The app itself (src/styles/tokens.css, components.css); Anki (interval
preview on grade buttons); GitHub contribution heatmap (streak
visualization); print dictionary front-matter (masthead, dotted-leader
index).
